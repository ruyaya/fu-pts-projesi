# FÜ PTS - Fırat Üniversitesi Plaka Tanıma Sistemi

Fırat Üniversitesi kampüs giriş kontrolü için geliştirilmiş; **Python** tabanlı görüntü işleme ve optik karakter tanıma (OCR) arka planı ile **Android Studio (Java)** tabanlı mobil arayüzü birleştiren otomasyon projesidir.


## 🛠️ Kullanılan Teknolojiler

* **Mobil Uygulama (Frontend):** Java, Android Studio, XML Layouts
* **Görüntü İşleme / OCR (Backend):** Python, OpenCV, EasyOCR


## 📌 Özellikler

* 📷 Kampüs giriş/çıkışlarında araç plakalarının tespiti ve okunması.
* 📱 Android uygulaması üzerinden araç kaydı ekleme, sorgulama ve personel yönetimi.
* 📋 Kayıtlı araç profillerini ve giriş/çıkış geçmişini görüntüleme.
